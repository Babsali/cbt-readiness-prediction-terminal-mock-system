### CHAPTER 1: INTRODUCTION
#### 1.1 Background of the Study
Computer Based Test CBT has become the standard for examinations in Nigeria. 
This project tailors a CBT Readiness Prediction System specifically for Terminal Mock Examinations in Secondary Schools.

#### 1.2 Problem Statement
Students often enter terminal exams unprepared. This system uses ML to predict readiness and recommend areas to improve before the actual exam.

#### 1.3 Aim and Objectives
Aim: To develop a Terminal Mock CBT system with ML prediction.
Objectives:
1. Design CBT examination interface
2. Implement ML model for readiness prediction
3. Provide performance analytics dashboard
